# ERP Console 预览说明

## 预览方式

1. 解压 `erp-console` 文件夹。
2. 在电脑终端进入解压后的 `erp-console` 目录。
3. 启动本地静态服务：

```bash
python3 -m http.server 4174
```

4. 浏览器打开：

```text
http://localhost:4174/
```

## 注意

- 页面使用 React/Babel 的 CDN 资源，预览电脑需要能访问网络。
- 不要直接双击打开 `index.html`，部分浏览器会限制本地脚本加载，建议使用上面的本地服务方式。
- 如果 4174 端口被占用，可以换成其他端口，例如：

```bash
python3 -m http.server 5188
```

然后打开：

```text
http://localhost:5188/
```
